# Legacy battle-flow art

`menu-battle-hero-v23.webp` is a byte-for-byte copy of the original artwork at
`luno_chess/assets/native_art/menu-battle-hero-v23.webp`. The retained legacy
`assets/luno-battle-flow-v23.js` references this path, but the transfer omitted
the copy. Restoring it repairs that actual asset reference and its compatibility
test; the active Flutter app continues to use its native asset.

The transfer manifest remains the historical record of the initial transfer.
