# Client state bug hunt

**1 yeni P2 kusur düzeltildi.** `refreshState`, generated-username consent/draft bookkeeping için gerçek `GameStore.requireUsernamePublication` sonucunu bekliyordu. Bu yerel preference yazımı boyunca account switch, bootstrap retry, access-denied veya dispose gerçekleşirse eski response yine başarıyla bitip `lastSyncAt`/`lastError` değiştiriyor, dispose durumunda `notifyListeners` assertion veriyordu. `api` içindeki mevcut HTTP owner kontrolleri bu son yerel await’i kapsamıyordu. Store bildirimi içinden eşzamanlı ownership değişimi de ayrı bir sınırdı.

Düzeltme: başlangıç owner’ı kontrol edilir; API’nin seçtiği completion owner, request generation ve yerel response epoch, username yazımı öncesi/sonrası ve store uygulamasının bildirimi sonrasında doğrulanır. Access failure korunur, eskimiş tamamlanma typed hata döndürür. İptal edilen state veya lifecycle callback’i yeni sync/başarı bildirimi oluşturmaz. Backend, oyun, ekonomi, entitlement, imza ve asset değiştirilmedi.

Önce **1 pass / 4 fail**, gerçek SharedPreferences platform yazımı gate edilerek kaydedildi (`refresh-before.log`). Tarihsel testte account-change/retry/access-denied yanlış başarı; dispose gerçek ChangeNotifier assertion verdi. Son iki store-notification sınırı daha sonra eklendi. Düzeltilmiş **7/7** yeni test ve bu testlerle birlikte sekiz ilgili dosya **91/91** geçti. Önceki 84 test ve geçerli assertion’lar değiştirilmedi. Koşular örtüşür; 7 ile 91 toplanmaz.
